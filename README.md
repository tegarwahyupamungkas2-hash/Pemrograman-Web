# Kalkulator Pengeluaran Harian Mahasiswa
## Deskripsi
Kalkulator Pengeluaran Harian Anak Kos adalah program sederhana berbasis web yang dibuat untuk membantu mahasiswa mengatur pengeluaran sehari-hari. Program ini dapat menghitung total pengeluaran dan sisa anggaran yang dimiliki.
## Tujuan
Membantu mahasiswa mencatat pengeluaran agar penggunaan uang lebih teratur dan sesuai anggaran.
## Fitur
- Mengatur anggaran uang.
- Menambahkan catatan pengeluaran.
- Memilih kategori pengeluaran.
- Menghitung total pengeluaran secara otomatis.
- Menampilkan sisa anggaran.
- Menghapus catatan pengeluaran.
## Teknologi
- HTML untuk struktur halaman.
- CSS untuk mengatur tampilan.
- JavaScript untuk perhitungan dan fungsi program.
## Cara Menjalankan
1. Unduh atau clone repository ini.
2. Buka folder proyek di Visual Studio Code.
3. Buka file index.html lalu jalankan melalui "Open with Live Server".
4. Masukkan anggaran dan catat pengeluaran.
